국내 주식 자동 분석 대시보드

Windows: start_windows.bat 더블클릭 후 브라우저 http://127.0.0.1:8765
Mac/Linux: 터미널에서 sh start_mac_linux.sh 실행 후 위 주소 접속
Python 3.10 이상, 인터넷 연결 필요.

종목명(정확한 이름) 또는 6자리 코드 입력 → 자동 분석.
데이터 소스: pykrx(KRX/네이버 스크래핑). 외부 사이트 정책 변경이나 접속 제한으로 조회가 실패할 수 있습니다.
최근 거래일: 데이터에 실제 존재하는 마지막 거래일. 당일 장중/종가 갱신 여부는 데이터 제공처에 따름.
AI 해설(선택): OPENAI_API_KEY 환경변수 설정 필요. 설정하지 않아도 정량 분석은 작동합니다.
실적/뉴스/산업 데이터는 자동 수집하지 않으므로 전체 100점과 텐베거 판정은 보류합니다.
가격대는 단순 기술적 휴리스틱이며 투자 추천이나 미래 가격 보장이 아닙니다.
프로그램을 인터넷에 공개하지 마세요. 로컬 실행 전용입니다.
